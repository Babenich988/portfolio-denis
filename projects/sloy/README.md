# Слой

Локальный статический концепт магазина небольшой булочной. Откройте `index.html` или запустите статический HTTP-сервер из этой папки.

Меню и цены вымышлены для демонстрации интерфейса. Корзина работает только в браузере, не принимает заказов и не отправляет данные. Фотографии показывают примеры выпечки, а не ассортимент магазина.

Фотокредиты и лицензии собраны в `credits.html`. Адаптивная и функциональная проверка описана в `DESIGN-REVIEW.md`.

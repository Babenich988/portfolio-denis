# Forge & Field — визуальные решения

## Направление

Практичный каталог оборудования, а не концепт luxury-магазина или рекламная кампания. Используются реальные фотографии предметов, ясные названия, короткие описания и заметное пояснение, что изображения служат примерами.

- `DESIGN_VARIANCE = 3/10` — ровная привычная структура и минимум декоративных эффектов.
- `MOTION_INTENSITY = 1/10` — только короткие состояния hover/focus; анимация не несёт смысловой нагрузки.
- `VISUAL_DENSITY = 5/10` — умеренная сетка, видимые кредиты и свободное пространство для фотографий.

## Токены

| Группа | Решение |
| --- | --- |
| Фон | светло-серый `#f4f6f5` и белые поверхности |
| Текст | тёмный графит `#202a30`, вспомогательный серый `#687378` |
| Акцент | сине-зелёный `#315a64` для действий и активных фильтров |
| Шрифт | локальный стек Segoe UI / Arial без внешних запросов |
| Углы | 3–4 px; скругления не используются как украшение |
| Фото | локальные фотографии Pexels, автор и ссылка видны рядом с каждым снимком |

## Компоненты и поведение

- Шапка с каталогом, информацией о макете и открытием демо-формы.
- Короткая hero-секция с реальной фотографией компрессорной установки.
- Поиск по названию, описанию, категории и автору; `Ctrl/⌘ K` переводит фокус в поиск.
- Категории — обычные кнопки с `aria-pressed`, сетка обновляется без перезагрузки.
- Карточка открывает нативный `dialog` с изображением и пояснением о фотопримере.
- Форма показывает локальный статус, не отправляя данные.
- Мобильная навигация, видимый фокус, skip link и режим reduced motion.

## Контентная правда

Forge & Field — вымышленный бренд. Снимки показывают реальные предметы, но не товары этого бренда. Цены, остатки, свойства моделей и партнёрство с видимыми на фото производителями не подразумеваются.

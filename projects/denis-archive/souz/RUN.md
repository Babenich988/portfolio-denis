# SOUZ — веб-мессенджер

Витрина включает исходный Next.js интерфейс и файлы конфигурации без зависимостей, секретов, логов и локальных моделей. Для запуска откройте терминал в этой папке и выполните:

```powershell
npm install
npm run dev
```

Затем откройте `http://localhost:3000`. Для работы некоторых функций могут понадобиться отдельные сервисы из исходного проекта.

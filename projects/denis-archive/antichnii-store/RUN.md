# Каталог Antichnii Store

Это исходная версия витрины цифровых товаров из папки портфолио Дениса. Для полной работы каталога нужен Node.js 20 или новее: откройте PowerShell в этой папке, выполните `node server.js` и перейдите на `http://127.0.0.1:3000`.

Без локального сервера основная страница открывается как статичный макет; запросы каталога и заказов требуют API.

# Комната роста

Локальный, статический концепт магазина комнатных растений. Откройте `index.html` или запустите любой статический сервер из этой папки.

## Что работает

- Адаптивная главная страница и каталог из пяти растений.
- Фильтр по предпочтительному освещению с доступным состоянием `aria-pressed`.
- Демонстрационная корзина с количеством, подсчётом суммы и закрытием через Escape/клик по фону.
- Отдельная страница с фотокредитами, лицензией и ботаническими источниками.

Корзина никуда не отправляет данные и не оформляет заказ. Цены и ассортимент условны. Фото иллюстрируют типы растений, а не конкретные товары.

## Запуск и проверка

```powershell
python -m http.server 4174
```

Проверка адаптивности и сценариев описана в `DESIGN-REVIEW.md`.

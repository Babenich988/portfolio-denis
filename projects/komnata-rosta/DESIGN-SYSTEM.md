# Комната роста — дизайн-система

## Направление

**Практичный магазин растений с ботанической карточкой-подсказкой.** Тёмный ботанический оттенок задаёт спокойную основу, глиняный акцент поддерживает фотографии, а тёплая бумажная поверхность помогает читать каталог. Запоминающийся элемент — не украшение, а навигация по свету у окна.

- `DESIGN_VARIANCE = 6/10` — активный hero и плотные цветовые акценты при ровной структуре каталога.
- `MOTION_INTENSITY = 2/10` — лёгкая обратная связь фильтров и корзины; без анимаций, влияющих на раскладку.
- `VISUAL_DENSITY = 5/10` — карточки несут полезные сведения по уходу, но фотографии получают достаточно места.

## Токены

| Роль | Значение |
| --- | --- |
| Основной фон | мягкая бумага `#f7f5ef` |
| Текст | тёмный графит `#292e2a` |
| Главный акцент | ботанический зелёный `#344a3e` |
| Второй акцент | приглушённая глина `#a86850` |
| Выделение | состаренная латунь `#d2bd8d` |
| Шрифт заголовков | `Arial Black` → `Impact` → `Arial`, с проверкой кириллицы |
| Шрифт текста | `Segoe UI` → `Arial`, системный стек без сетевой загрузки |
| Поверхности | без градиентов и стеклянных карточек; тонкие границы, небольшие радиусы |

## Контент и поведение

- Каталог комнатных растений с фильтром по предпочтениям к освещению.
- Цена и наличие — демонстрационные значения, не коммерческое предложение.
- Фото с фотобанка иллюстрируют вид растения, а не конкретный экземпляр магазина; источник указывается рядом.
- Корзина работает только в браузере; оплату и оформление заказа макет не выполняет.
- Уходовые подписи краткие и сверяются с университетской службой Extension; токсичность для животных указывается там, где источник это подтверждает.
- Адаптивный каталог, доступное состояние фильтра и reduced-motion без зависимости от анимации.

## Намеренно не используется

Сгенерированные растения, вымышленные отзывы, медицинские обещания, расплывчатые claims об «очищении воздуха», градиентные фоны, декоративные blobs и невидимые состояния заказа.

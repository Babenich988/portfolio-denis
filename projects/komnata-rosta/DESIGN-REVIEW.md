# Проверка дизайна и поведения

## Замысел

«Комната роста» оформлена как ботанический полевой журнал: лесная зелень, тёплая бумага и терракотовые акценты, вертикальный навигационный индекс и асимметричная раскладка каталога. Фильтр по свету и переключение фотографий помогают осматривать растения, а корзина остаётся демонстрационной.

## Чек-лист

- [x] 1440 × 900: иерархия hero, весь верхний экран, нет наложения заголовка и фото.
- [x] 1280 × 800: карточки и навигация не переполняются.
- [x] 390 × 844 и 375 × 812: одна колонка карточек, видны CTA и переключатели без горизонтальной прокрутки.
- [x] Все локальные изображения загружаются; подписи и тексты альтернатив описывают реальные фотографии.
- [x] Фильтры показывают корректные карточки и обновляют счётчик.
- [x] Корзина считает позиции/сумму; кнопки количества работают; Escape и фон закрывают диалог; фокус возвращается на кнопку открытия.
- [x] Нет ошибок JavaScript в консоли и горизонтального переполнения.
- [x] Страница содержит авторов фото и ботанические источники.
- [x] Reduced motion отключает необязательные переходы.

Примечание: отмеченные выше проверки Playwright относятся к предыдущей раскладке. После экспериментального обновления выполнена только статическая проверка синтаксиса JavaScript; новый визуальный вид в браузере отдельно не проверялся.

«Союз»: тестирование мессенджера и AI-сервиса

Командный учебный проект · 2026

В университетском мессенджере подготовил тестируемый прототип отдельного AI-сервиса, API-контракты и проверки, чтобы команда могла подключать функции в mock-режиме. В текущей работе над мессенджером вручную проверяю новые изменения, фиксирую найденные дефекты в GitHub и участвую в их разборе до слияния pull request.

Мой вклад

  • Описал форматы запросов и ответов для health-check и пяти AI-операций.
  • Подготовил pytest-проверки и Docker-окружение.
  • Настроил GitHub Actions для проверок проекта и документировал интеграцию.

Проверяемый результат

В локальном контрольном прогоне 28 августа 2026 года прошли 8 тестов.

AI-операции возвращают тестовые mock-результаты. Это не подключённая production-модель и не оценка качества на реальных пользователях.

Командный учебный проект · 2025

Участвовал в ручном тестировании Windows Forms-приложения для создания и редактирования BPMN-схем. В истории GitHub также видны мои изменения в поведении BPMN-блоков и текста, удалении элементов, рабочих листах и подсказках.

KINIS был командным проектом. Я не приписываю себе разработку всего редактора; сборка и отдельные сценарии сейчас не перепроверялись.

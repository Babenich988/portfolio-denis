# Портфолио сайтов Дениса

Откройте `index.html` в браузере. Если нужен интерактивный Stride, запустите локальный сервер из этой папки: `python -m http.server 8000`, затем перейдите на `http://localhost:8000`.

В витрине собраны девять работ: пять сайтов и концептов из предыдущей подборки, а также OLD BANK, Antichnii Store, WHH и MP. Повторяющиеся учебные версии объединены. Финансовый лендинг представлен отдельным SVG-макетом. Antichnii Store полностью загружается с локальным сервером; подсказка запуска находится в его папке.

Актуальные версии WHH и MP синхронизированы из исходных папок пользователя в `projects/denis-archive`. Из папки Дениса включены OLD BANK, Antichnii Store, WHH и MP.

QA-портфолио находится в `qa/index.html`. Обе страницы связаны переключателем «Сайты / QA»: основная витрина показывает веб-проекты, QA-раздел — два командных учебных проекта с отдельно обозначенным личным вкладом и границами опыта.
